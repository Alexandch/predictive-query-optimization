# Основная многодоменная XGBoost-модель

Модель обучена на авиационной и розничной предметных областях: 13 760 реальных
измерений, 6 474 уникальных SQL и 70 структурных шаблонов. Повторные SQL
агрегируются медианой. Вход состоит из структурных признаков SQL, статистики
отношений и оценочных полей `EXPLAIN`; пользовательский запрос для прогноза не
выполняется.

- файл: `xgboost_query_time.joblib`;
- SHA-256: `737ACD01B6D52890CE3B3CB0C7179BA88B47481A05AA83CE35D09656C3A44065`;
- преобразование цели: `identity`;
- конфигурация: 500 деревьев, depth 6, learning rate 0,04;
- parameter-holdout: R² 0,9710, MAE 13,81 мс, median AE 4,95 мс;
- unseen-template stress: R² 0,8655, MAE 41,22 мс.

На независимом авиационном контроле MAE снизился с 637,76 до 602,60 мс, R²
вырос с 0,376 до 0,442. На независимом розничном контроле MAE снизился с 320,83
до 307,24 мс, R² вырос с −0,678 до −0,460. Это единственный проверенный вариант
цикла, который улучшил оба домена, поэтому он назначен основной моделью.

Полные внутренние метрики находятся в `metrics.json`, ранжирование признаков —
в `feature_importance.json`, протокол внешнего сравнения — в
`docs/multidomain-experiment.md`.
