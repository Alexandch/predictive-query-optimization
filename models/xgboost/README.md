# Итоговая XGBoost-модель

Универсальная модель обучена на 4 800 измерениях 40 типов запросов к PostgreSQL.
Повторные SQL-тексты агрегированы медианой. Вход модели состоит только из
структурных признаков SQL и оценочных полей `EXPLAIN`, доступных без выполнения
запроса.

- файл модели: `xgboost_query_time.joblib`;
- SHA-256: `75111A53515B71DD3C05D440315CBFD0EB6F6511AFB125E4AB086FD22463DA3F`;
- Python: 3.13;
- XGBoost: 3.4;
- scikit-learn: 1.9;
- основной holdout R²: 0,9760;
- основной holdout MAE: 3,47 мс;
- stress-R² новых структур: 0,8823;
- stress-MAE: 9,06 мс.

Выбрано преобразование цели `log1p`: вариант `identity` немного улучшил
обычный holdout, но снизил stress-R² до 0,6296. Смешивание измерений разных
серий также отклонено из-за временного dataset shift.

Файл `metrics.json` содержит полный отчёт, а `feature_importance.json` —
ранжирование входных признаков.
