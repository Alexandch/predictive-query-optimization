# Итоговая XGBoost-модель

Универсальная модель обучена на 10 400 измерениях 52 типов запросов к PostgreSQL.
Повторные SQL-тексты агрегированы медианой. Вход модели состоит только из
структурных признаков SQL, статистики отношений и оценочных полей `EXPLAIN`,
доступных без выполнения запроса.

- файл модели: `xgboost_query_time.joblib`;
- SHA-256: `A6418453AB44E709BB66619BE09798DA94EDAA39C15CCA1DAB8FF3E3E8B17C34`;
- Python: 3.13;
- XGBoost: 3.4;
- scikit-learn: 1.9;
- основной holdout R²: 0,9661;
- основной holdout MAE: 12,52 мс;
- 90,15% прогнозов основного holdout имеют ошибку не более 20%;
- stress-R² новых структур: 0,9582;
- stress-MAE: 27,37 мс.

Выбрано преобразование цели `log1p`: вариант `identity` оказался хуже и на
обычном holdout (`R² = 0,9603`), и на stress-проверке (`R² = 0,9256`).

Файл `metrics.json` содержит полный отчёт, а `feature_importance.json` —
ранжирование входных признаков.
