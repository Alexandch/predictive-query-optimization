# DQN-агент индексных рекомендаций

Модель обучена на 1 820 записях реального опыта: 480 параметризованных SQL,
24 структурных шаблона, `NOOP` и до трёх индексных действий для каждого
запроса. Каждое действие проверялось двумя измерениями в откатываемой
транзакции PostgreSQL.

- файл: `dqn_index_advisor.pt`;
- SHA-256: `AFFFBD8B817E6B7BAF5B4F453C78692134C914DC3E32E2F742E1DE835353CA14`;
- PyTorch: 2.14 CPU;
- основной holdout accuracy: 59,76%;
- случайная стратегия: 24,39%;
- основной mean regret: 0,0626;
- случайный mean regret: 0,3523;
- стресс-тест новых шаблонов: 31,0% против 23,0% случайно.

`metrics.json` относится к выбранной основной модели. `stress_metrics.json`
фиксирует отдельное обучение, из которого целиком исключены пять типов
запросов. Стресс-модель не используется для пользовательского инференса.
