# DQN-агент индексных рекомендаций

Модель обучена на 3 940 записях реального опыта: 826 уникальных SQL,
52 структурных шаблона, `NOOP` и до трёх индексных действий для каждого
запроса. Каждое действие проверялось в откатываемой транзакции PostgreSQL с
контрольным baseline до и после индекса.

- файл: `dqn_index_advisor.pt`;
- SHA-256: `75FC4BF3EDFD937E3D6D7117243392AE1B21E847C8CE2FB7F9ED956DA0C2F8AE`;
- PyTorch: 2.14 CPU;
- основной holdout accuracy: 62,50%;
- случайная стратегия: 28,57%;
- основной mean regret: 0,0725;
- случайный mean regret: 0,2913;
- стресс-тест новых шаблонов: 41,56% против 23,38% случайно;
- stress mean regret: 0,1844 против 0,2833 случайно.

`metrics.json` относится к выбранной основной модели. `stress_metrics.json`
фиксирует отдельное обучение, из которого целиком исключены десять типов
запросов. Стресс-модель не используется для пользовательского инференса.

Состояние учитывает статистику PostgreSQL, а действие — совпадения ключей
индекса с `WHERE`, `JOIN`, `ORDER BY` и выбираемыми колонками. Loss объединяет
регрессию reward и ранжирование действий одного запроса (`ranking_weight=0.10`).
