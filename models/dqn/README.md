# DQN-агент индексных рекомендаций

Модель обучена на 1 191 записи реального опыта: 400 параметризованных SQL,
40 структурных шаблонов, `NOOP` и до двух индексных действий для каждого
запроса. Каждое действие проверялось в откатываемой транзакции PostgreSQL с
контрольным baseline до и после индекса.

- файл: `dqn_index_advisor.pt`;
- SHA-256: `21D5440C9FA1776210BD45B5582D019ED5BF304CF9BE49F6E60744E25503977B`;
- PyTorch: 2.14 CPU;
- основной holdout accuracy: 54,69%;
- случайная стратегия: 31,25%;
- основной mean regret: 0,0461;
- случайный mean regret: 0,2613;
- стресс-тест новых шаблонов: 54,84% против 33,87% случайно;
- stress mean regret: 0,0840 против 0,2253 случайно.

`metrics.json` относится к выбранной основной модели. `stress_metrics.json`
фиксирует отдельное обучение, из которого целиком исключены восемь типов
запросов. Стресс-модель не используется для пользовательского инференса.
