# 0.8.41 — изменения SQL в редакторе

Текстовый diff и повтор полного SQL убраны из результатов переписывания.
Статус проверки эквивалентности, фактические времена и пороги остаются отдельно.

В паре редакторов обычного SQL и SELECT внутри транзакции:

- изменённые строки выделены жёлтым;
- добавленные — зелёным;
- удалённые строки исходника — красным;
- при наведении на изменение показывается исходный фрагмент;
- если фрагмент только удалён, справа выделена соседняя оставшаяся строка,
  в подсказке указано, что удалено перед/после неё.

Сравнение обновляется при выборе кандидата и ручных правках. Оно не выполняет
SQL, не переписывает редакторы и не меняет положение курсора, undo или правила
применения. Совпадение/отличие цвета не означает эквивалентность или ускорение:
для применения по-прежнему нужна отдельная фактическая проверка.

Внешние отступы не считаются изменением. Содержимое многострочных строковых
литералов и кавычечных идентификаторов сравнивается без удаления пробелов;
незавершённый SQL сравнивается как обычный текст. Подсказка экранирует HTML.
На SQL больше 5000 строк/500000 символов подсветка выключается, чтобы сравнение
не задерживало ввод; причина доступна при наведении.

## Проверка

Полный набор с PostgreSQL: **691 passed**. Новые тесты проверяют замену,
добавление, удаление и конец файла; многострочные литералы/Unicode; реальное
событие наведения Qt; отсутствие подсказки на неизменённой строке и ниже SQL;
сохранение текста/курсора/undo; обновление при редактировании и переносе строк;
сброс после очистки и ограничение размера. Сохранены тесты выбора кандидата,
блокировки непроверенного варианта и SELECT-замены в контексте транзакции.

Визуальная проверка: `artifacts/release-0841/line-diff.png` и
`old-sql-tooltip.png`. Это неподтверждённый демонстрационный SQL без подключения
к БД. Исполняемый smoke переписывания также проверяет цветовые выделения и
подсказку со старым SQL через Qt-событие, наряду с эквивалентностью, отказом при
изменении дубликатов и неизменностью исходного редактора.
