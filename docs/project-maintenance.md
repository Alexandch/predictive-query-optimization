# Структурный аудит и очистка: 30.10.2026

На начало аудита: 193 Python-файла вне артефактов/сборки — 106 модулей src,
67 файлов тестов, 17 скриптов и 3 файла упаковки, около 34 тысяч строк.
Проверены AST всех файлов, полные дубли, перекрывающие определения функций,
локальные импорты, CLI в pyproject.toml, ссылки скриптов из документации и сборки.
Это структурный аудит, а не заявление о полном построчном ревью всех алгоритмов.

Полных дублей файлов и перекрывающих определений тестов не найдено. Модули,
недостижимые из основных CLI, используются исследовательскими скриптами:
генераторы workload, контроль выборок, повторные измерения, оценка регрессий.
Удаление их вместе с тестами разрушило бы воспроизведение экспериментов.
Особенно важно не переносить автоматически файлы, хеши которых зафиксированы
в исторических протоколах обучения.

Удалён устаревший `scripts/check_rewrite_examples.py`: частичная диагностика
двух logistics-примеров заменена фиксированным прогоном
`python -m pqo.optimization_control`. Ссылка в документации обновлена;
исторические отчёты сохранены. Скрипт можно восстановить из Git, например
посмотреть `git show 0efedd5:scripts/check_rewrite_examples.py`.

По отдельному согласию пользователя удаляются старые установщики
0.8.18–0.8.23, каталог `build`, `.pytest_cache` и `__pycache__` исходников,
тестов, скриптов и упаковки. Оставляются текущая переносимая сборка 0.8.25,
установщики 0.8.25 и 0.8.24, установленное приложение, модели, dataset, БД,
пользовательские artifacts и `.venv`. Кэш создаётся заново автоматически;
старые удалённые установщики при необходимости надо пересобрать.
Основная очистка выполнена. Небольшой `.pytest_cache` остался: повторная команда
удаления отклонена политикой среды. Модели, данные и пользовательские отчёты
не удалялись.

После очистки для этапа транзакций заново собрана и установлена 0.8.26.
Затем добавлен подбор общих кандидатов (0.8.27) и пробы чтений на копии
(0.8.28); текущая установленная/переносимая сборка — 0.8.28. Новые `build`/кэши относятся к текущей
сборке и не являются оставшимися старыми релизами. Установщики 0.8.24/0.8.25
сохранены, как было согласовано; 0.8.26/0.8.27/0.8.28 добавлены отдельно.
Для проб создана отдельная БД `pqo_university_index_lab`; это намеренная
тестовая копия, не устаревший кэш. Исходная БД не перезаписывалась.

Следующая очистка должна опираться на связи и назначение файлов, а не на
принцип «не импортируется из desktop — значит лишнее». Тесты отрицательных
случаев и безопасности сохраняются независимо от частоты их запуска.
