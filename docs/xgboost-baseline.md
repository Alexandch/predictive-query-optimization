# Разработка модели XGBoost

## Текущая многодоменная модель

После авиационного этапа добавлена независимая схема `retail`. Текущий набор
содержит 13 760 измерений, 6 474 уникальных SQL, 70 шаблонов и 18 предметных
таблиц в двух доменах. Основная модель использует `identity`, 500 деревьев,
`max_depth=6` и `learning_rate=0.04`.

- parameter-holdout: R² 0,9701, MAE 14,18 мс;
- unseen-template stress: R² 0,7761, MAE 47,75 мс;
- независимая авиация: R² 0,442, MAE 602,60 мс;
- независимая розница: R² −0,460, MAE 307,24 мс.

По MAE и R² модель улучшила прежнюю основную версию на обоих независимых
контролях. Полный многодоменный протокол приведён в
`multidomain-experiment.md`.

## Авиационный эксперимент v9 (история)

- исходных измерений: 10 400;
- уникальных SQL после медианной агрегации: 3 398;
- структурных шаблонов: 52;
- предметных таблиц: 8;
- диапазон времени: 0,085–3 003,83 мс;
- 95-й процентиль: 634,08 мс;
- целевая переменная: `actual_total_time_ms`;
- одинаковые SQL-тексты не разделяются между train и test;
- гиперпараметры подбираются только внутри обучающей части.

Счётчики фактически прочитанных буферов и целевое время исключены из входа
модели. Пользовательский прогноз использует `EXPLAIN (FORMAT JSON)` и не
выполняет SQL-запрос.

Версия v5 остаётся исторически лучшим узким экспериментом на прежних коротких
запросах. На авиационном этапе рабочей моделью была v9: она охватывает 52 структуры и диапазон до
3 секунд. Абсолютная MAE выросла вместе с масштабом времени, зато stress-R²
превысил целевые 0,90 и вырос на 0,0759 относительно v7.

## Параметры авиационной модели v9 (история)

- `n_estimators`: 500;
- `max_depth`: 8;
- `learning_rate`: 0,04;
- `min_child_weight`: 10;
- `subsample`: 0,70;
- `colsample_bytree`: 1,0;
- преобразование целевой переменной: `log1p`.

Основной parameter-holdout:

- R²: 0,9661;
- MAE: 12,52 мс;
- медианная абсолютная ошибка: 4,19 мс;
- RMSE: 41,21 мс;
- доля прогнозов с ошибкой до 20%: 90,15%.

## Стресс-тест новых шаблонов

Из обучения целиком удаляются 13 из 52 структурных типов. На них рабочая
модель получает:

- R²: 0,9582;
- MAE: 27,37 мс;
- медианная абсолютная ошибка: 17,97 мс;
- RMSE: 53,30 мс.

Stress-R² вырос на 0,0759 относительно v7. Это подтверждает пользу увеличения
базы, структурного расширения и признаков статистики отношений. Следующее
расширение следует проводить уже на другой предметной схеме, а не простым
повторением тех же параметров.

## Интеграция с десктопным приложением

Функция `predict_sql_query` является независимым Python API. Она получает SQL,
запрашивает оценочный план PostgreSQL и возвращает прогноз вместе с основными
характеристиками плана. PyQt сможет вызывать её без импорта кода обучения и без
выполнения пользовательского запроса.
