# Фиксация baseline перед обучением

Команда `pqo-baseline` создаёт отдельный снимок SHA-256 основных моделей,
метрик, обучающих наборов и четырёх контрольных нагрузок. Исторические manifest
контрольных экспериментов при этом не перезаписываются.

```powershell
.\.venv\Scripts\pqo-baseline.exe create
.\.venv\Scripts\pqo-baseline.exe check
```

Актуальный снимок хранится в `models/baseline/manifest.json`. Проверка должна
возвращать `"valid": true` до и после каждого эксперимента. Кандидаты обучаются
только в `artifacts/models`; файлы `models/xgboost` и `models/dqn` заменяются
лишь после прохождения всех внешних контролей.

Manifest фиксирует байтовые хеши. На Windows изменение LF на CRLF также будет
считаться изменением файла, даже если JSONL-содержимое логически совпадает.
