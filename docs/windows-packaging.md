# Сборка Windows

Установщик для Windows 10/11 x64 собирается PyInstaller и Inno Setup 6.
Он включает Python, Qt, зависимости и выбранные модели; PostgreSQL подключается
отдельно. Версии пакета и установщика заданы в
[pyproject.toml](../pyproject.toml) и [installer.iss](../packaging/installer.iss).

## Сборка

Нужны созданный `.venv` и установленный Inno Setup 6. Проверенная конфигурация
сборки использует Windows x64 и Python 3.13.3; другие конфигурации проверяются отдельно.

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_windows.ps1
```

Скрипт устанавливает группы `desktop,build`, создаёт иконку, собирает EXE,
запускает smoke-проверку загрузки Qt и моделей и формирует установщик.
Результаты:

- `dist/PredictiveQueryOptimization` — каталог приложения;
- `dist/installer/PredictiveQueryOptimization-Setup-<version>.exe` — установщик.

Для сборки без установщика используйте `-SkipInstaller`, без повторной установки
зависимостей — `-SkipDependencyInstall`. Обычная сборка очищает кэш PyInstaller;
`-Incremental` оставляет его и не подходит для проверки, что исправления точно
попали в выпуск.

## Проверка дистрибутива

```powershell
.\dist\PredictiveQueryOptimization\PredictiveQueryOptimization.exe --smoke-test
```

Дополнительно проверьте обычный запуск с `QT_QPA_PLATFORM=windows`, последовательные
прогнозы, обработку ошибки/отмены, переключение источников и фактические операции
на отдельном стенде. Offscreen smoke не заменяет нативные события Windows.
Автоматизация чистого профиля и EXE описана в [testing.md](testing.md).

В Windows индексные DQN выполняют инференс через NumPy-экспорт тех же весов,
без загрузки PyTorch в глубокую проверку. При изменении модели и признаков
обновляйте приложение вместе с артефактами. `Prediction features are missing`
означает несовместимый контракт, а не необходимость добавить нулевые признаки.

Если системная политика блокирует неподписанную сборку, для её распространения
нужны доверенная подпись или решение администратора. Изменять системную политику
для прохождения проверки приложение не должно.

## Установка и данные пользователя

По умолчанию приложение устанавливается в
`%LOCALAPPDATA%\Programs\PredictiveQueryOptimization`, создаёт ярлык меню «Пуск»
и необязательный ярлык рабочего стола. Удаление доступно через параметры Windows
или `unins000.exe`.

Локальные журналы и результаты хранятся в
`%LOCALAPPDATA%\PredictiveQueryOptimization\artifacts`, настройки — в QSettings.
Пути можно изолировать через `PQO_APP_DATA_ROOT` и `PQO_SETTINGS_FILE`.
Обновление не должно сбрасывать выбранную модель, её резервную копию и профили.
Перед выпуском проверьте это на отдельном профиле.
