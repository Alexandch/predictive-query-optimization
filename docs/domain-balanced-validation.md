# Подбор доли Pagila на development-данных

## Протокол

Доля новой предметной области выбиралась без чтения `production_control`,
`retail_control`, `logistics_zero_shot` и `chbenchmark_control`. Валидатор:

1. объединяет основной обучающий набор и Pagila;
2. сворачивает повторные измерения одного SQL медианой;
3. отдельно внутри aviation, retail и Pagila откладывает 25% структурных
   шаблонов;
4. обучает одинаковый XGBoost для каждой доли и seed 21, 42, 84;
5. считает normalized MAE отдельно по каждому домену и усредняет их с равным
   весом;
6. выбирает минимум средней macro-normalized MAE, затем худшего seed и меньшей
   доли.

Выборки вложены: запросы меньшей доли всегда входят в выборку большей доли.
Это исключает подмену эффекта объёма случайно более удачным составом запросов.

## Результат выбора доли

| Доля Pagila | Macro normalized MAE | Macro R² | Худший MAE |
|---:|---:|---:|---:|
| 0% | 0,9360 | −1,1058 | 1,0844 |
| **10%** | **0,3662** | **0,6372** | **0,4040** |
| 25% | 0,3760 | 0,5904 | 0,4729 |
| 50% | 0,3743 | 0,5913 | 0,4529 |
| 75% | 0,3776 | 0,5797 | 0,4090 |
| 100% | 0,3752 | 0,5640 | 0,4273 |

Дополнительные точки 55–90% также не превзошли 10%. Полная таблица сохранена
в `models/evaluation/domain_mix_summary.csv`.

Выбранный набор содержит 14 004 измерения, 6 515 уникальных SQL и 100
шаблонов. В него вошли 244 измерения Pagila: 41 уникальный SQL из всех 30
шаблонов. SHA-256 набора:
`5E635D3F5E108F98091888CD0C5E6C02E7B313414CDAE47EA5F665DC89FC6E1D`.

## Финальные кандидаты и решение

После фиксации доли обучены три кандидата с неизменными гиперпараметрами.

| Seed | Parameter R² / MAE | Unseen-template R² / MAE |
|---:|---:|---:|
| Основная модель | **0,9701** / 14,18 мс | **0,7761 / 47,75 мс** |
| 21 | 0,9468 / 14,80 мс | 0,6888 / 54,19 мс |
| 42 | **0,9788 / 12,94 мс** | 0,6760 / 62,95 мс |
| 84 | 0,9512 / **13,57 мс** | 0,6751 / 53,05 мс |

Ни один кандидат не прошёл внутренний шлюз: улучшение обычного parameter split
не сохранилось на новых структурах запросов. Поэтому внешние запечатанные
контроли не запускались, а основная модель не заменялась. Результат показывает,
что дальнейшее простое добавление строк исчерпано; следующий эксперимент должен
менять представление домена или архитектуру обучения.

## Воспроизведение

```powershell
.\.venv\Scripts\pqo-domain-mix.exe `
  dataset\postgresql\multidomain_training.csv `
  dataset\postgresql\pagila_training.csv `
  artifacts\domain-mix-final `
  --fractions 0 0.1 0.25 0.5 0.55 0.6 0.65 0.7 0.75 0.8 0.85 0.9 1 `
  --seeds 21 42 84

.\.venv\Scripts\pqo-train.exe `
  artifacts\domain-mix-final\selected_training.csv `
  artifacts\models\xgb_domain_mix_010_seed42 `
  --target-transform identity --no-tune --seed 42
```
