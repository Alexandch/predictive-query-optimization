# Десктопное PyQt6-приложение

Приложение объединяет прогноз XGBoost и рекомендацию DQN в одном
локальном интерфейсе. Пользовательский SQL не выполняется: для анализа
используется оценочный `EXPLAIN` без `ANALYZE`.

## Запуск

```powershell
docker compose up -d --wait
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[desktop]"
.\.venv\Scripts\pqo-desktop.exe
```

По умолчанию используются PostgreSQL на `localhost:55432` и выбранные модели
из каталога `models`. Параметры можно изменить на вкладке «Настройки».
Пароль PostgreSQL не записывается в `QSettings` и существует только в памяти
текущего процесса.

## Вкладки

- **Анализ** — ввод `SELECT`/`WITH`, прогноз времени, показатели плана и
  безопасная индексная рекомендация. DDL только показывается, но не
  применяется автоматически.
- **История** — последние 200 анализов из схемы `pqo`.
- **Настройки** — подключение к PostgreSQL, пути к XGBoost/DQN и проверка связи.
- **Обучение** — повторное обучение XGBoost или DQN на указанном датасете с
  выводом итоговых метрик.

Анализ, доступ к истории, проверка связи и обучение выполняются в фоновых
потоках, поэтому окно не зависает во время долгих операций.
